Short, because there is little to hide.

How this website treats you, and where each product keeps its own policies.

01 / This website

entergex.com does not track you.

This website sets no cookies, runs no scripts, and loads nothing from other companies: no analytics, no advertising, no embedded fonts or videos. We do not know who visits.

The site is hosted on GitHub Pages. Like any web host, GitHub receives your IP address and basic browser details when your browser asks for a page, and handles them under the GitHub Privacy Statement.

If you email us, we use your message and address only to answer you.
